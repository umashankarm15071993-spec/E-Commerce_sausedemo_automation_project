## 📖 Project Overview

This project is a robust Selenium automation framework developed for the **SauceDemo** e-commerce application using **Python**, **Pytest**, and the **Page Object Model (POM)**. The framework is designed to be scalable, reusable, and easy to maintain while following industry-standard automation practices.

---

## ✨ Key Features

- ✅ Page Object Model (POM)
- ✅ Pytest Test Framework
- ✅ Data-Driven Testing using Excel

- ✅ Allure Reporting

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/umashankarm15071993-spec/E-Commerce_sausedemo_automation_project.git
```

Move into the project

```bash
cd E-Commerce_sausedemo_automation_project
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Execute Tests

Run all test cases

```bash
pytest
```

Run with verbose output

```bash
pytest -v -s
```

Generate Allure Results

```bash
pytest --alluredir=allure-results
```

Open Allure Report

```bash
allure serve allure-results
```
